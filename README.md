# Thay Brown — Portfolio

Thay Brown's portfolio site, live at [thaythecoder.netlify.app](https://thaythecoder.netlify.app).

A personal site for me, a full-stack software engineer with 5+ years in fintech and DevOps, now building full-stack web experiences for businesses. It leads with the engineering work — how a project goes from first commit to production — then shows the apps and the client sites that came out of it.

## Tech stack

- HTML, CSS, vanilla JavaScript — no framework, no build step
- Static site, hosted on Netlify

## How to run it

There is nothing to install and no build step — it is a static site.

1. Open `Port-2/index.html` in a browser, or serve the folder:
   ```
   python3 -m http.server 8000
   ```
   then open http://localhost:8000
